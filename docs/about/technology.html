Why json-tool?

Technology

On this page

Technology ​

json-tool is built with React, TypeScript, Tailwind CSS and CodeMirror. It ships as a web app and as an Electron desktop app.

Web Workers ​

The JSON strings are processed in a Web Worker, so the interface stays fast and responsive even while formatting large documents. This technology decision was made to ensure that the tool is fast and responsive at the same time it provides long term support and constant updates.

Read more: Web Workers to the Rescue — How to Work with JSON Strings without Blocking User Interactions
