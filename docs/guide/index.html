User manual ​

Welcome to the json-tool user manual. json-tool is a privacy-first JSON formatter, validator and beautifier. It runs entirely in your browser: none of your JSON ever leaves your machine.

The tool at a glance ​

json-tool lets you:

  • Format JSON content with a click of a button.
  • Validate JSON and be warned about invalid content.
  • Beautify the result with configurable indentation.
  • Search, clean and copy the content easily.
  • Inspect JSON as a table, as shape statistics and as a diff between two documents.

The views ​

Switch between views using the tabs in the header:

ViewTab / routeDescription
Homehome tab, /Format and validate JSON in two editors
Tabletable tab, /tableSee the JSON as a table
Shapeshape tab, /schemaSee the JSON shape and statistics
Diffdiff tab, /diffCompare two JSON documents
Settingssettings tab, /settingsConfigure the editors and features

The documentation icon in the header (Docs) opens this manual in a new tab.

The header ​

From left to right the header shows:

  • The JSON tool logo (goes back home) and the view tabs.
  • The history button (only when the JSON History feature is enabled). It opens a drawer with the JSON you have used previously.
  • The validate json checkbox. When on, invalid JSON is reported below the editors.
  • The sync scroll checkbox. When on, both editors scroll together on the same relative line.
  • The dark mode switch.

The footer ​

The footer contains the license (CC0 1.0 Universal), a Found an issue? link to the GitHub issue tracker and a Buy me a coffee link.

A quick first run ​

  1. Open the app and paste or type JSON in the editor on the left.
  2. The editor on the right shows the formatted result as you type.
  3. Use the tabs to switch to the table view, the shape view, the diff view or the settings.
