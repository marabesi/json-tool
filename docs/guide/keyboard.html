Keyboard shortcuts ​

json-tool can be used without a mouse. Every control can be reached with Tab and activated with Enter or Space, and each action also has a dedicated shortcut so you do not have to tab through the page.

Press ? (when you are not typing in an editor) to open the shortcut list inside the app. The list only shows the shortcuts available on the current page.

Navigation and views ​

ShortcutAction
Alt + 1 or Alt + HomeGo to the home view
Alt + 2Go to the table view
Alt + 3Go to the shape view
Alt + 4Go to the diff view
Alt + 5 or Alt + SGo to the settings view
Alt + HOpen or close the history drawer (when JSON History is enabled)
Alt + D or Alt + Shift + DOpen the documentation in a new tab

Header ​

ShortcutAction
Alt + JToggle validate json
Alt + YToggle sync scroll
Alt + MToggle dark mode

Editors ​

ShortcutAction
Alt + Shift + WFocus the working editor (left)
Alt + Shift + RFocus the result or compare editor (right)
TabMove to the next control, including out of the JSON editors
Shift + TabMove to the previous control
Ctrl/⌘ + FSearch in the working editor
Ctrl/⌘ + Shift + FSearch in the result editor

The editors do not capture Tab, so you can always leave an editor and reach its toolbar, the divider, the other editor, the header and the footer.

The Alt + Shift + W and Alt + Shift + R shortcuts jump directly into the left and right editors, so you can start typing without using the mouse or tabbing through the page.

Working editor (left) ​

ShortcutAction
Ctrl/⌘ + FSearch in the working editor
Alt + VPaste from the clipboard
Alt + OUpload a JSON file
Alt + DeleteDelete all

Result editor (right, home view) ​

ShortcutAction
Ctrl/⌘ + Shift + FSearch in the result editor
Alt + Shift + TFocus the space tabulation input
Alt + Shift + SClean spaces
Alt + Shift + NClean new lines
Alt + Shift + BClean new lines and spaces
Alt + Shift + CCopy the result

Diff view ​

The original editor uses the working editor shortcuts. The compare editor uses:

ShortcutAction
Ctrl/⌘ + Shift + FSearch in the compare editor
Alt + Shift + VPaste from the clipboard
Alt + Shift + OUpload a JSON file
Alt + Shift + DeleteDelete all

Dialogs and full screen ​

ShortcutAction
?Open or close the shortcut list
EscClose the shortcut list or the history drawer, or exit the table full screen

Controls ​

ShortcutAction
TabMove to the next control, including out of the JSON editors
Shift + TabMove to the previous control
Enter or SpaceActivate the focused button, link or checkbox
Left / Right arrowResize the editors when the divider between them is focused
Home / EndUse the minimum or maximum editor width when the divider is focused

The editors do not capture Tab, so you can always leave an editor and reach its toolbar, the divider, the other editor, the header and the footer.

The focused control is highlighted with a yellow outline. The history drawer keeps the focus inside it while it is open, and returns the focus to the history button when it is closed.

Editors ​

The editors support the usual editing keys, including undo/redo and the CodeMirror search panel. Press Esc to close the search panel.
