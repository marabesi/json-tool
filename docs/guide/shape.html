Shape view ​

The shape view summarizes the structure of your JSON. Switch to it using the shape tab in the header (route /schema). Paste JSON into the working editor and the right pane shows an aggregate analysis of the whole document plus the same analysis for every nested object/array shape.

Statistics ​

For the whole document and for every nested shape, json-tool reports:

StatisticMeaning
ObjectsTotal objects in the subtree
ArraysTotal arrays in the subtree
PropertiesDistinct property names
ValuesTotal values (property values plus array elements)
Avg properties / objectProperty values per object
FilledCount of values that are not empty (with percentage)
EmptyCount of values that are empty (with percentage)
Type breakdownCount and percentage for each JSON type, sorted by count

A value is considered empty when it is null, "", [] or {}.

Nested shapes ​

  • Every nested object and array gets the same statistics, scoped to that part of the JSON.
  • Repeated shapes are aggregated into a single node. For example, 32 objects with an author field produce one author node with an instance count of 32.
  • A nested shape appears only under its parent path; paths are never duplicated across levels.
  • Fields inside an array are measured against the number of elements; nested objects inherit the enclosing population, so percentages never exceed 100%.

Each nested shape is a collapsible section showing its path, its type (object, array or scalar) and how many instances it has, followed by the same statistics panel and its own nested shapes.

Use Expand all and Collapse all to open or close every nested shape at once. The keyboard shortcuts are Alt + E (expand all) and Alt + W (collapse all).
