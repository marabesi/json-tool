Get started
Open the app

Format and beautify

Paste your JSON and get a clean, readable result instantly. Configurable indentation (2 spaces by default), clipboard and file upload support.

Validate

Turn on validation to be warned the moment your JSON is not valid, with the error shown right below the editors.

Table view

Inspect an array of objects as a table, with fuzzy search across every column and nested values.

Shape and statistics

Understand the structure of a document at a glance, with statistics for the whole document and every nested shape.

Diff

Compare two JSON documents and see every added, removed and changed value, with paths and before/after values.

Why json-tool? ​

json-tool is a simple tool that does not track you, does not store your data and does not sell your data. All the JSON processing happens in your browser, in a Web Worker, so the interface stays responsive even with large documents.
